# ai-candidate-system

# Система автоматизированного первичного отбора кандидатов с использованием ИИ

## О проекте

Проект направлен на разработку системы, которая помогает автоматизировать первичный отбор кандидатов с использованием технологий искусственного интеллекта.

## Команда

- Нурали - анализ требований, функции системы, контроль требований
- Иван - критерии оценки, этапы отбора, контроль качества
- Сергей - документация, взаимная проверка, контроль результатов
